## 🚀 Key Features at a Glance

* **🎭 Playwright Modern Locators**: Automatically generates resilient, user-first locators (`page.getByRole()`, `page.getByTestId()`, `page.getByLabel()`, `page.getByPlaceholder()`).
* **🎯 Smart XPath & CSS Engine**: Generates unique, highly stable XPaths and CSS selectors ranked by score, ignoring volatile/dynamic IDs and framework hashes.
* **❄️ Dropdown & Menu Freeze Mode**: Solves the auto-closing dropdown problem! Freeze transient menus, tooltips, and Angular/React/Bootstrap dropdowns using a 3-second countdown or hotkey.
* **🌳 Interactive DOM Breadcrumbs**: Navigate up and down the DOM tree with live hover highlights and 1-click inspection travel.
* **🧩 Custom XPath Attribute Matrix**: Check/uncheck attributes (`id`, `name`, `type`, `class`, `text()`) to assemble custom XPaths in real time with instant match count feedback.
* **🛠️ Native DevTools Studio**: Seamlessly integrated into Chrome DevTools as a dedicated **TestPath** tab alongside *Console* and *Network* with live `$0` selection sync.
* **🔴 User Flow Recorder**: Record test actions directly into executable test scripts for Playwright, Selenium, and Cypress.
* **⚡ Multi-Framework Export**: 1-click ready-to-paste snippets in **Playwright** (JS, Python, Java, C#), **Selenium** (Java, Python, JS, C#), **Cypress**, **Robot Framework**, and **Puppeteer**.

## 📦 How to Install (Step-by-Step)

TestPath works on any Chromium-based browser (**Google Chrome**, **Microsoft Edge**, **Brave**, **Opera**).

### Step 1: Download & Extract
1. Download **[`testpath-protected-extension.zip`](testpath-protected-extension.zip)**.
2. Right-click the downloaded `.zip` file and select **Extract All...** (or unzip it) into a convenient folder on your computer.

### Step 2: Open Extensions Page
1. Open your browser and navigate to:
   * **Chrome**: `chrome://extensions`
   * **Edge**: `edge://extensions`
   * **Brave**: `brave://extensions`

### Step 3: Enable Developer Mode
* In the top-right corner of the Extensions page, toggle the **Developer mode** switch to **ON**.

```
┌────────────────────────────────────────────────────────┐
│ Extensions                       Developer mode  [ON]  │
│ [Load unpacked]  [Pack extension]  [Update]            │
└────────────────────────────────────────────────────────┘
```

### Step 4: Load TestPath
1. Click the **"Load unpacked"** button in the top-left corner.
2. Select the folder where you extracted the extension (select the folder containing `manifest.json`).
3. **That's it! 🎉** TestPath is now installed.

### Step 5: Pin & Start Using
1. Click the **Puzzle Piece (Extensions)** icon in your browser toolbar.
2. Click the **Pin 📌** icon next to **TestPath** to keep it readily available.
3. Open any webpage and click the TestPath icon or press <kbd>F12</kbd> to access the DevTools **TestPath** tab!
